# Conector SharePoint Online

Status: **Em desenvolvimento**. Nenhuma chamada ao Microsoft Graph é realizada.

O conector futuro deverá usar Microsoft Entra ID/MSAL em modo somente leitura,
começando por Site Pages e depois bibliotecas com parsers seguros para formatos
explicitamente suportados. SharePoint Server local, escrita e permissões
administrativas não fazem parte desta etapa.
