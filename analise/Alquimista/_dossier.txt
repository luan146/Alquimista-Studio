## 1. Resumo executivo

O ALQuimista Studio é uma aplicação desktop em Python/PySide6 para descobrir, selecionar, extrair, transformar e consolidar conteúdo de plataformas de conhecimento em arquivos Markdown, manifestos JSON e índices SQLite.

A arquitetura atual possui quatro camadas principais:

1. **Domínio e persistência**
   - Modelos Pydantic em `alquimista/models.py`.
   - Persistência JSON, SQLite e transações de arquivos em `alquimista/storage.py`.
   - Seleções estruturadas por fonte, contêiner e documento.

2. **Integrações**
   - Contrato abstrato em `alquimista/connectors/base.py`.
   - Registro de conectores em `alquimista/connectors/registry.py`.
   - Conectores implementados para Confluence, GitBook e Zendesk.
   - Notion e SharePoint aparecem como conectores de desenvolvimento/parciais.

3. **Serviços**
   - Descoberta, extração incremental, conversão Markdown e consolidação em `alquimista/services.py`.
   - Retry, limitação de taxa e tratamento de erros em `alquimista/client.py`.

4. **Interface**
   - Interface PySide6 centralizada em `alquimista/ui/main_window.py`.
   - Mixins e controllers para fontes, conexão, seleção, árvores e operações.
   - Workers com `QThreadPool` e workers multiprocessados com `multiprocessing`.

**Avaliação geral:** o núcleo possui boas proteções contra persistência acidental de credenciais, escrita parcial, cancelamento, respostas HTTP inválidas e inconsistências básicas de seleção. O maior risco operacional está na diferença entre o que a suíte valida e o que o usuário final executa: o CI testa código-fonte em Windows/Python 3.12, mas não testa adequadamente o executável PyInstaller, instalação limpa, Chromium empacotado, Linux ou integrações reais.

## 2. Finalidade real do sistema

O sistema permite:

1. Criar ou abrir um projeto.
2. Configurar uma ou mais fontes de conhecimento.
3. Validar a conexão.
4. Descobrir contêineres, espaços, pastas e documentos.
5. Selecionar documentos individualmente ou em lote.
6. Baixar conteúdo.
7. Converter HTML ou Markdown de origem para Markdown normalizado.
8. Gravar páginas individuais.
9. Criar e atualizar um manifesto incremental.
10. Gerar relatórios de execução e falhas.
11. Consolidar páginas em pacotes Markdown.
12. Preservar metadados, hierarquia e hashes para execuções futuras.

A própria documentação resume o fluxo operacional:

```text
1. Abra ou crie um projeto.
2. Adicione uma ou mais fontes.
3. Valide a URL e a conexão.
4. Descubra espaços, contêineres e páginas.
5. Selecione espaços e páginas, revise o formato e escolha a saída.
6. Execute a aquisição e, se desejado, a consolidação.
```

```python
class SourceConfig(Model):
    id: str = Field(default_factory=lambda: uuid.uuid4().hex)
    name: str = "Nova fonte"
    source_type: str = "confluence_rest"
    base_url: str = ""
    space_key: str = ""
    space_name: str = ""
    root_mode: Literal["title", "id", "space"] = "title"
    root_value: str = ""
    root_page_id: str = ""
    auth_mode: AuthMode = AuthMode.PUBLIC
    username: str = ""
    include_root: bool = False
    enabled: bool = True
    connector_options: dict[str, Any] = Field(default_factory=dict)
    selected_page_ids: list[str] = Field(default_factory=list)
    consolidation_excluded_page_ids: list[str] = Field(default_factory=list)
    state_file: str | None = Field(default=None, exclude=True)

    @field_validator("id")
    @classmethod
    def validate_id(cls, value: str) -> str:
        return validate_source_identifier(value)

    @field_validator("base_url")
    @classmethod
    def validate_url(cls, value: str) -> str:
        value = value.strip().rstrip("/")
        if not value:
            return ""
        parsed = urlparse(value)
        if parsed.scheme not in {"http", "https"} or not parsed.netloc:
            raise ValueError(
                "A URL deve começar com http:// ou https:// e conter um host."
            )
        if parsed.username or parsed.password:
            raise ValueError("Não inclua usuário ou senha na URL.")
        return value

    @model_validator(mode="after")
    def require_https_for_authenticated_access(self) -> "SourceConfig":
        if (
            self.base_url
            and self.auth_mode != AuthMode.PUBLIC
            and urlparse(self.base_url).scheme != "https"
        ):
            raise ValueError("A autenticação exige uma URL HTTPS.")
        return self

    @field_validator("connector_options")
    @classmethod
    def reject_secret_options(cls, value: dict[str, Any]) -> dict[str, Any]:
        forbidden = ("token", "secret", "password", "cookie", "refresh", "authorization")
        for key in value:
            if any(part in str(key).casefold() for part in forbidden):
                raise ValueError(
                    "Credenciais devem permanecer somente durante a sessão; "
                    "não inclua segredos na configuração do projeto."
                )
        return value
```

**FATO OBSERVADO:** há bloqueio explícito de URLs com usuário/senha, exigência de HTTPS para acesso autenticado e rejeição de chaves de configuração que aparentem conter segredos.

**INTERPRETAÇÃO:** a proteção é baseada no nome das chaves. Um segredo armazenado em uma chave semanticamente neutra, como `value` ou `options`, não seria necessariamente detectado.

### `ProjectConfig`

**Arquivo:** `alquimista/models.py`

```python
class ProjectConfig(Model):
    schema_version: int = SCHEMA_VERSION
    project_id: str = Field(default_factory=lambda: uuid.uuid4().hex)
    project_name: str = "Projeto ALQuimista"
    output_dir: str = "ALQuimista_Base"
    sources: list[SourceConfig] = Field(default_factory=list)
    selections: list[KnowledgeSelection] = Field(default_factory=list)
    markdown: MarkdownOptions = Field(default_factory=MarkdownOptions)
    extraction: ExtractionOptions = Field(default_factory=ExtractionOptions)
    consolidation: ConsolidationOptions = Field(default_factory=ConsolidationOptions)

    @model_validator(mode="after")
    def unique_sources(self) -> "ProjectConfig":
        ids = [source.id for source in self.sources]
        if len(ids) != len(set(ids)):
            raise ValueError("O projeto contém fontes com identificadores duplicados.")
        return self

    def to_dict(self) -> dict[str, Any]:
        data = self.model_dump(mode="json")
        data["schema_version"] = self.schema_version
        for source in data["sources"]:
            source.pop("state_file", None)
        return data

    def selected_keys_for(self, source_id: str) -> set[str]:
        from .selection import SelectionStore

        selected = SelectionStore.from_selections(
            self.selections
        ).keys_for_source(source_id)
        source = next((item for item in self.sources if item.id == source_id), None)

        has_structured_source_selection = any(
            item.source_id == source_id for item in self.selections
        )

        if source and not has_structured_source_selection:
            selected.update(
                f"{source.id}:{source.space_key}:{page_id}"
                for page_id in source.selected_page_ids
            )
        return selected

    @classmethod
    def from_dict(cls, data: dict[str, Any]) -> "ProjectConfig":
        migrated = dict(data)
        version = int(migrated.get("schema_version", 2))

        if version < SCHEMA_VERSION:
            migrated["schema_version"] = 3 if version < 3 else SCHEMA_VERSION
            migrated.setdefault("project_id", uuid.uuid4().hex)

            for source in migrated.get("sources", []):
                source.setdefault("source_type", "confluence_rest")
                source.setdefault("space_name", "")
                source.setdefault("root_page_id", "")
                source.setdefault("consolidation_excluded_page_ids", [])

            selections = migrated.setdefault("selections", [])

            for source in migrated.get("sources", []):
                container_id = str(source.get("space_key", "") or "__legacy__")
                for page_id in source.get("selected_page_ids", []) or []:
                    candidate = {
                        "source_id": str(source.get("id", "")),
                        "container_id": container_id,
                        "document_id": str(page_id),
                        "selected": True,
                    }
                    if candidate not in selections:
                        selections.append(candidate)

        return cls.model_validate(migrated)
```

**FATO OBSERVADO:** há compatibilidade explícita entre seleções antigas baseadas apenas em `page_id` e o novo formato estruturado.

**RISCO:** o campo antigo `selected_page_ids` e o novo `selections` coexistem. O código evita misturar ambos quando já há seleção estruturada para uma fonte, mas projetos parcialmente migrados dependem de regras de fallback.

### `FileTransaction`

**Arquivo:** `alquimista/storage.py`  
**Linhas:** 58–154

```python
class FileTransaction:
    def __init__(self, base: Path) -> None:
        self.base = base.resolve()
        self.base.mkdir(parents=True, exist_ok=True)
        self.directory = Path(
            tempfile.mkdtemp(prefix=".alquimista-txn-", dir=self.base)
        )
        self.staged: dict[Path, Path] = {}
        self.deletions: set[Path] = set()
        self._committed = False

    def _target(self, path: Path) -> Path:
        resolved = path.resolve()
        if resolved != self.base and self.base not in resolved.parents:
            raise StorageError(
                f"O caminho sai da transação permitida: {path}"
            )
        return resolved

    def stage_text(self, path: Path, content: str) -> None:
        target = self._target(path)
        staged = self.directory / "staged" / f"{uuid.uuid4().hex}.tmp"
        atomic_write_text(staged, content)
        previous = self.staged.get(target)
        if previous:
            previous.unlink(missing_ok=True)
        self.staged[target] = staged
        self.deletions.discard(target)

    def stage_delete(self, path: Path) -> None:
        target = self._target(path)
        staged = self.staged.pop(target, None)
        if staged:
            staged.unlink(missing_ok=True)
        self.deletions.add(target)

    def commit(self) -> None:
        backups = self.directory / "backups"
        applied: list[tuple[Path, Path | None]] = []

        try:
            operations = [
                (target, staged)
                for target, staged in sorted(
                    self.staged.items(),
                    key=lambda item: str(item[0]),
                )
            ]

            for target, staged in operations:
                target.parent.mkdir(parents=True, exist_ok=True)
                backup: Path | None = None

                if target.exists():
                    backup = backups / f"{uuid.uuid4().hex}.bak"
                    backup.parent.mkdir(parents=True, exist_ok=True)
                    os.replace(target, backup)

                applied.append((target, backup))
                os.replace(staged, target)

            for target in sorted(self.deletions, key=str):
                if target.exists():
                    backup = backups / f"{uuid.uuid4().hex}.bak"
                    backup.parent.mkdir(parents=True, exist_ok=True)
                    os.replace(target, backup)
                    applied.append((target, backup))

            self._committed = True

        except OSError as exc:
            rollback_errors: list[str] = []

            for target, backup in reversed(applied):
                try:
                    target.unlink(missing_ok=True)
                    if backup and backup.exists():
                        target.parent.mkdir(parents=True, exist_ok=True)
                        os.replace(backup, target)
                except OSError as rollback_exc:
                    rollback_errors.append(str(rollback_exc))

            detail = (
                f" Rollback incompleto: {'; '.join(rollback_errors)}"
                if rollback_errors
                else ""
            )
            raise StorageError(
                f"Falha ao publicar a transação de arquivos: {exc}.{detail}"
            ) from exc

        finally:
            if self._committed:
                self.close()
```

**BUG PROVÁVEL:** a transação tenta restaurar arquivos anteriores, mas o rollback depende de operações adicionais de filesystem que também podem falhar. O próprio código informa “Rollback incompleto” apenas depois que a restauração já falhou. Isso é uma limitação operacional, não uma prova de corrupção em condições normais.

**PONTO POSITIVO:** staging, `os.replace`, backups e confinamento de caminhos fornecem uma base razoável para escrita atômica.

### Retry HTTP

**Arquivo:** `alquimista/client.py`  
**Linhas:** 125–204

```python
def _request(
    self,
    path: str,
    *,
    params: dict[str, Any] | None = None,
    expect_json: bool = True,
) -> Any:
    url = (
        path
        if path.startswith(("http://", "https://"))
        else f"{self.base_url}{path}"
    )
    last_error: Exception | None = None

    for attempt in range(1, self.options.retry_count + 1):
        self.token.check()
        self.rate_limiter.wait()
        response: requests.Response | None = None

        try:
            response = self.session.get(
                url,
                params=params,
                timeout=(
                    self.options.connect_timeout_seconds,
                    self.options.timeout_seconds,
                ),
            )

            if response.status_code == 401:
                raise AuthenticationError(
                    "Autenticação recusada ou sessão expirada (HTTP 401)."
                )

            if response.status_code == 403:
                raise PermissionDeniedError(
                    "A conta não possui permissão para este conteúdo (HTTP 403)."
                )

            if response.status_code == 404:
                raise ResourceNotFoundError(
                    "O espaço ou a página não foi encontrado (HTTP 404)."
                )

            transient = response.status_code == 429 or response.status_code in {
                500,
                502,
                503,
                504,
            }

            if transient:
                if attempt == self.options.retry_count:
                    if response.status_code == 429:
                        raise RateLimitError(
                            "O Confluence limitou as requisições (HTTP 429)."
                        )
                    raise ConfluenceConnectionError(
                        f"O Confluence permaneceu indisponível "
                        f"(HTTP {response.status_code})."
                    )

                delay = self._retry_delay(response, attempt)
                self.log(
                    f"Tentativa {attempt} falhou com HTTP "
                    f"{response.status_code}; nova tentativa em {delay:.1f}s."
                )
                self.token.wait(delay)
                continue

            response.raise_for_status()

            if not expect_json:
                return response.text

            try:
                return response.json()
            except ValueError as exc:
                raise InvalidResponseError(
                    "O Confluence retornou uma resposta JSON inválida."
                ) from exc

        except (
            AuthenticationError,
            PermissionDeniedError,
            ResourceNotFoundError,
            InvalidResponseError,
            RateLimitError,
        ):
            raise
        except (requests.Timeout, requests.ConnectionError) as exc:
            last_error = exc
            if attempt == self.options.retry_count:
                break
            delay = self._retry_delay(response, attempt)
            self.log(
                f"Falha de rede na tentativa {attempt}; "
                f"nova tentativa em {delay:.1f}s."
            )
            self.token.wait(delay)
        except requests.RequestException as exc:
            raise ConfluenceConnectionError(f"Falha HTTP: {exc}") from exc

    raise ConfluenceConnectionError(
        f"Não foi possível conectar ao Confluence após "
        f"{self.options.retry_count} tentativas: {last_error}"
    )
```

**FATO OBSERVADO:** `401`, `403` e `404` não são repetidos; `429` e determinados `5xx` são considerados transitórios.

**PONTO POSITIVO:** o token de cancelamento é verificado antes da requisição e durante o atraso.

```python
                if summary.updated_at
                else None

            if (
                old

                and (not summary_etag or old.etag == summary_etag)
                and old.updated_at == summary_updated
```

### Descoberta hierárquica do Confluence

**Arquivo:** `alquimista/connectors/confluence.py`  
**Linhas:** 184–247

```python
@staticmethod
def _ordered_pages(client: Any, container_id: str) -> list[dict[str, Any]]:
    list_roots = getattr(client, "list_root_pages", None)
    list_children = getattr(client, "list_child_pages", None)

    if not callable(list_roots) or not callable(list_children):
        return client.list_pages()

    ordered: list[dict[str, Any]] = []
    seen: set[str] = set()

    def has_children(page: dict[str, Any]) -> bool:
        if isinstance(page.get("has_children"), bool):
            return bool(page["has_children"])

        children = page.get("children")
        if isinstance(children, dict) and isinstance(
            children.get("size"),
            int,
        ):
            return children["size"] > 0

        links = page.get("_links") or {}
        return isinstance(links, dict) and bool(links.get("child"))

    def collect_children(parent_id: str) -> None:
        cursor: str | None = None

        while True:
            payload = list_children(
                parent_id,
                cursor=cursor,
                limit=100,
            )
            results = payload.get("results", [])

            if not isinstance(results, list):
                break

            for page in results:
                page_id = str(page.get("id", ""))

                if not page_id or page_id in seen:
                    continue

                seen.add(page_id)
                ordered.append(page)

                if has_children(page):
                    collect_children(page_id)

            cursor = payload.get("next_cursor")

            if not cursor or not results:
                break

    cursor: str | None = None

    while True:
        payload = list_roots(cursor=cursor, limit=100)
        results = payload.get("results", [])

        if not isinstance(results, list):
            break

        for page in results:
            page_id = str(page.get("id", ""))

            if not page_id or page_id in seen:
                continue

            seen.add(page_id)
            ordered.append(page)

            if has_children(page):
                collect_children(page_id)

        cursor = payload.get("next_cursor")

        if not cursor or not results:
            break
```

**BUG PROVÁVEL:** a função usa recursão sem limite explícito de profundidade. O conjunto `seen` evita ciclos por IDs repetidos, mas não evita estouro de pilha em uma hierarquia extremamente profunda.

**PONTO POSITIVO:** há deduplicação por ID e fallback para `list_pages()` quando a API não expõe descoberta hierárquica.

**Arquivo:** `alquimista/connectors/registry.py`  
**Linhas:** 12–78

```python
@dataclass(frozen=True)
class ConnectorDescriptor:
    source_type: str
    display_name: str
    integration_name: str
    status: ConnectorStatus | str
    implemented: bool
    capabilities: ConnectorCapabilities
    factory: ConnectorFactory | None = None
    configuration_fields: tuple[str, ...] = ()
    limitations: tuple[str, ...] = ()

    @property
    def operational(self) -> bool:
        return self.status_code in {
            ConnectorStatus.AVAILABLE,
            ConnectorStatus.EXPERIMENTAL,
        }


class ConnectorRegistry:
    def __init__(
        self,
        descriptors: list[ConnectorDescriptor] | None = None,
    ) -> None:
        self._descriptors = {
            descriptor.source_type: descriptor
            for descriptor in descriptors or []
        }

    def register(self, descriptor: ConnectorDescriptor) -> None:
        self._descriptors[descriptor.source_type] = descriptor

    def get(self, source_type: str) -> ConnectorDescriptor:
        try:
            return self._descriptors[source_type]
        except KeyError as exc:
            raise ValueError(
                f"Conector não registrado: {source_type}"
            ) from exc

    def available(self) -> list[ConnectorDescriptor]:
        return [
            item
            for item in self.all()
            if item.status_code in {
                ConnectorStatus.AVAILABLE,
                ConnectorStatus.EXPERIMENTAL,
            }
            and item.implemented
            and item.factory
        ]

    def create(
        self,
        source: SourceConfig,
        **kwargs: Any,
    ) -> KnowledgeSourceConnector:
        descriptor = self.get(source.source_type)

        if (
            not descriptor.operational
            or not descriptor.implemented
            or descriptor.factory is None
        ):
            raise ValueError(
                f"A integração {descriptor.display_name} "
                "ainda está em desenvolvimento."
            )

        return descriptor.factory(source, **kwargs)
```

**FATO OBSERVADO:** conectores não implementados podem permanecer registrados, porém `create()` bloqueia sua criação em runtime.

**INTERPRETAÇÃO:** isso é útil para a UI exibir o roadmap, mas aumenta a possibilidade de um projeto salvo referenciar uma integração que parece disponível visualmente, mas falha somente quando iniciada.

### Worker baseado em `QRunnable`

**Arquivo:** `alquimista/ui/workers.py`

```python
class WorkerSignals(QObject):
    succeeded = Signal(object)
    failed = Signal(str, str)
    progress = Signal(int, int, str)
    log = Signal(str)
    finished = Signal()


class Worker(QRunnable):
    def __init__(
        self,
        function: Callable[..., Any],
        *,
        token: CancellationToken | None = None,
    ) -> None:
        super().__init__()
        self.function = function
        self.token = token or CancellationToken()
        self.signals = WorkerSignals()

    @Slot()
    def run(self) -> None:
        try:
            result = self.function(
                self.token,
                self.signals.progress.emit,
                self.signals.log.emit,
            )
        except Exception as exc:
            self.signals.failed.emit(
                str(exc),
                traceback.format_exc(),
            )
        else:
            self.signals.succeeded.emit(result)
        finally:
            self.signals.finished.emit()
```

**PONTO POSITIVO:** `finished` é emitido no bloco `finally`, inclusive quando ocorre exceção.

```python
def _worker_main(
    task: Task,
    args: tuple[Any, ...],
    kwargs: dict[str, Any],
    cancel_event: Any,
    messages: Any,
) -> None:
    context = TaskContext(cancel_event, messages)
    status = "error"

    try:
        context.raise_if_cancelled()
        result = task(context, *args, **kwargs)
        context.raise_if_cancelled()

        pickle.dumps(
            result,
            protocol=pickle.HIGHEST_PROTOCOL,
        )

        messages.put(
            WorkerMessage(
                kind="success",
                result=result,
            )
        )
        status = "success"

    except TaskCancelled:
        messages.put(
            WorkerMessage(
                kind="cancelled",
                status="cancelled",
            )
        )
        status = "cancelled"

    except BaseException as error:
        messages.put(_error_message(error))
        status = "error"

    finally:
        messages.put(
            WorkerMessage(
                kind="finished",
                status=status,
            )
        )
```

### Cancelamento de processos

**Arquivo:** `alquimista/ui/process_workers.py`  
**Linhas:** 217–251

```python
def cancel(self) -> None:
    if self._cancel_event is not None:
        self._cancel_event.set()

def shutdown(self, timeout: float = 5.0) -> None:
    if timeout < 0:
        raise ValueError("timeout must be non-negative")

    if self._process is None:
        self.close()
        return

    if self.is_alive:
        self.cancel()

        if not self.wait(timeout):
            self._process.terminate()
            self._process.join(timeout)

            if self.is_alive:
                kill = getattr(self._process, "kill", None)

                if kill is not None:
                    kill()

                self._process.join(timeout)

    self.close()
```

**PONTO POSITIVO:** o sistema tenta cancelamento cooperativo antes de `terminate()` e `kill()`.

**RISCO:** se uma tarefa estiver em uma operação externa não interrompível, o encerramento forçado pode abandonar estado intermediário no serviço externo ou no processo filho. O uso de `FileTransaction` reduz o risco de arquivos parcialmente publicados, mas não elimina efeitos externos.

## 19. Performance

### Possíveis gargalos

1. Descoberta completa de páginas pode percorrer muitos elementos.
2. Construção de árvores Qt pode ser custosa para milhares de nós.
3. `_leaf_items()` percorre recursivamente toda a árvore.
4. Consolidação reabre e processa entradas do manifesto.
5. A extração faz chamadas individuais por documento.
6. O cache lazy usa limites fixos:
   - `_LAZY_BATCH_LIMIT = 100`.
   - `_LAZY_MAX_ITEMS = 5000`.

**INTERPRETAÇÃO:** esses limites são seguros como defaults conservadores, mas podem ser inadequados para instâncias muito grandes ou APIs com limites diferentes.

### Paginação hierárquica

A descoberta usa `limit=100` para raízes e filhos. A função continua usando cursores enquanto houver `next_cursor`, portanto não está limitada a uma única página. O limite de 5.000 aplica-se ao caminho lazy, não necessariamente a todos os fluxos completos.

### Seleção

`_leaf_items()` executa uma travessia recursiva da árvore:

```python
def _leaf_items(self) -> list[QTreeWidgetItem]:
    leaves: list[QTreeWidgetItem] = []

    def walk(item: QTreeWidgetItem) -> None:
        if item.childCount() == 0 and item.text(1):
            leaves.append(item)

        for index in range(item.childCount()):
            walk(item.child(index))

    for index in range(self.selection_tree.topLevelItemCount()):
        item = self.selection_tree.topLevelItem(index)
        if item is not None:
            walk(item)

    return leaves
```

**Arquivo:** `alquimista/ui/mixins/selection_mixin.py`  
**Linhas:** 277–290.

**BUG PROVÁVEL:** em árvores anormalmente profundas, a recursão pode atingir o limite da pilha. Para hierarquias normais, o risco parece baixo.

### Controle de cancelamento

```python
class CancellationToken:
    def __init__(self) -> None:
        self._event = threading.Event()

    def cancel(self) -> None:
        self._event.set()

    @property
    def cancelled(self) -> bool:
        return self._event.is_set()

    def check(self) -> None:
        if self.cancelled:
            raise ExtractionCancelledError(
                "Operação cancelada pelo usuário."
            )

    def wait(self, seconds: float) -> None:
        if seconds > 0 and self._event.wait(seconds):
```

### Rate limiter

```python
class RateLimiter:
    def __init__(
        self,
        requests_per_second: float,
        token: CancellationToken,
    ) -> None:
        self.interval = 1.0 / max(0.1, requests_per_second)
        self.last_request = 0.0
        self.token = token

    def wait(self) -> None:
        remaining = self.interval - (
            time.monotonic() - self.last_request
        )

        if remaining > 0:
            self.token.wait(remaining)

        self.last_request = time.monotonic()
```

## 33. Contexto pronto para revisor externo

O ALQuimista Studio é uma aplicação desktop PySide6 que transforma conteúdo de plataformas externas em uma base Markdown local.

A configuração persistida é representada por `ProjectConfig`, com `SourceConfig`, `KnowledgeSelection`, opções de Markdown, extração e consolidação. A seleção nova usa chaves `source_id:container_id:document_id`, mas o sistema ainda mantém compatibilidade com listas antigas de `page_id`.

A integração com plataformas é feita por `KnowledgeSourceConnector`, criado por `ConnectorRegistry`. Confluence, GitBook e Zendesk são os caminhos principais. Notion e SharePoint estão registrados como desenvolvimento e bloqueados na criação quando `implemented=False`.

A extração passa por `ExtractionService`, que carrega manifesto anterior, calcula hashes, compara timestamps/ETags, preserva documentos inalterados e baixa somente conteúdo alterado. A publicação usa `FileTransaction`, que grava em staging, cria backups e tenta rollback em falhas.

A UI é centralizada em `MainWindow`, com mixins e controllers. A descoberta pode ser completa ou lazy. O cache lazy usa SQLite e guarda metadados por fonte, escopo, contêiner, documento, cursor e query.

Há dois modelos de concorrência: `QRunnable` dentro do `QThreadPool` e `ProcessWorker` em processo separado com spawn, fila IPC, serialização preventiva e cancelamento cooperativo.

Os maiores riscos não são falhas óbvias no núcleo de domínio, mas:

- build distribuído não executado no CI;
- Chromium não validado no executável;
- integrações reais fora do gate;
- divergência entre Python declarado, CI e instaladores;
- coexistência de chaves legadas e novas;
- concentração excessiva na UI;
- rollback limitado à capacidade do filesystem;
- cobertura incompleta dos controllers/mixins.

## 34. Conclusão

O projeto possui uma base arquitetural razoavelmente madura para uma aplicação desktop de extração documental:

- modelos bem definidos;
- conectores abstraídos;
- persistência com proteção contra caminhos inválidos;
- atualização incremental;
- cancelamento;
- retry;
- cache;
- testes sintéticos abrangentes.

Entretanto, a confiabilidade percebida pelo usuário final ainda não é equivalente à qualidade demonstrada pelos testes. O CI valida principalmente o código-fonte e os fluxos sintéticos em Windows/Python 3.12. Ele não valida de forma efetiva:

- o `.exe` final;
- uma instalação limpa;
- assets e imports empacotados;
- Chromium;
- execução Linux;
- versões alternativas de Python;
- respostas reais das plataformas externas.

A segunda IA deve concentrar sua reavaliação em quatro eixos:

1. **Consistência dos identificadores e migrações.**
2. **Atomicidade real da persistência.**
3. **Escalabilidade da descoberta e da interface.**
4. **Distância entre o código testado e o produto distribuído.**
